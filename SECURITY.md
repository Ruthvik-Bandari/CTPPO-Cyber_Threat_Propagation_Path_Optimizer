# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within CTPPO, please send an email to bandari.ru@northeastern.edu.

All security vulnerabilities will be promptly addressed.

## Responsible Use

This tool is designed for **authorized security testing only**. Please ensure you:

1. Have written permission before scanning any system
2. Only test systems you own or are authorized to test
3. Follow responsible disclosure practices
4. Comply with all applicable laws and regulations

## Legal Disclaimer

Unauthorized access to computer systems is illegal. The authors of this software are not responsible for any misuse. By using this software, you agree to use it only for lawful purposes on systems you are authorized to test.

## Authorized Test Targets

For testing purposes, use only these intentionally vulnerable applications:

- http://testphp.vulnweb.com (Acunetix)
- http://demo.testfire.net (IBM)
